## 操作使用提示

### 手势操作说明

1. 双击屏幕
    - 左侧 1/5 处 快退
    - 中间 暂停
    - 右侧 1/5 处 快进
2. 横向滑动调整进度
3. 竖向滑动
    - 左侧调节亮度
    - 右侧调节音量
4. 长按倍速
    - 长按并横向滑动调节倍速值
        - 向上滑动即可锁定倍速
5. 双指缩放调节视频显示大小
6. 放大后双指拖动画面位置
    - 点击画面比例选择任意选项还原

### 键盘快捷键操作说明

适用于电脑，以及连接外接键盘的平板、手机。快捷键仅在当前页面生效。

#### 首页、视频列表和目录

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+F | 显示搜索栏并聚焦搜索框 |
| Ctrl+Shift+F | 打开全局搜索 |
| Ctrl+O | 打开视频文件导入 |
| Ctrl+Shift+O | 打开文件夹导入 |
| Ctrl+Shift+N | 打开新建文件夹弹窗，可选择父目录 |
| Ctrl+B | 展开或收起侧栏 |
| Ctrl+D | 切换列表视图和目录视图 |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | 切换列表、卡片、网格布局 |
| Alt+↑ | 目录返回上一级 |
| Alt+← | 页面返回；首页目录中返回上一级 |
| Ctrl+A | 进入多选并全选当前显示的视频；焦点在侧栏文件夹区域时全选可选文件夹 |
| F2 | 重命名焦点项或唯一选中项 |
| Delete | 打开选中项或焦点项的删除确认弹窗 |
| Esc | 退出多选、关闭侧栏或清除搜索 |

全选只针对当前展示的视频，不递归选择子目录中的视频。删除仍按弹窗选择执行。

#### 播放页

| 快捷键 | 操作 |
| --- | --- |
| 空格 / K | 播放或暂停 |
| ← / → | 快退或快进，步长沿用设置中的秒数 |
| Shift+← / Shift+→ | 每次快退或快进 1 秒 |
| ↑ / ↓ | 增大或减小音量 |
| Shift+↑ / Shift+↓ | 提高或降低亮度，每次 5% |
| M | 静音或恢复静音前音量 |
| F / F11 | 切换全屏或横屏显示 |
| PageUp / PageDown | 播放上一个或下一个视频 |
| [ / ] | 降低或提高一档播放速度 |
| \ | 恢复 1 倍速 |
| V | 关闭字幕，或恢复字幕显示 |
| T | 打开字幕设置菜单 |
| P | 展开或收起播放列表 |
| Esc | 优先关闭弹层、播放列表，再退出全屏或恢复自动屏幕方向 |
| Alt+← | 返回上一页，播放列表打开时先关闭播放列表 |

- 画面获焦时，空格和方向键控制播放；按钮、菜单或播放列表获焦时，优先执行控件本身的操作。
- Tab / Shift+Tab 在可操作控件间切换焦点，方向键移动焦点，回车打开焦点视频或文件夹。
- 输入框内保留文字输入、光标移动、全选和删除；弹窗、菜单优先处理自己的按键。
- 进度、音量和亮度支持长按连续调整；播放暂停、切换视频、全屏等操作每次按键只执行一次。
- Esc 只退出当前显示模式，不会反向进入全屏。手机、平板横屏时恢复自动方向，最终方向随设备姿态决定。
- 鼠标滚轮仍可按设置调节音量或亮度。

### 如何进入隐私空间？

1. 通过设置页隐私空间按钮进入
2. 通过搜索框输入密码进入
3. 通过首页双指往外划开进入
    - 类似于放大照片的手势

### 如何设置外挂字幕？

- 通过列表页长按视频选择导入字幕

### 为什么有的视频可以选择彻底删除，有些则不行？

> 这和源视频位置有关，位置不相同则权限不相同

- 源视频位于相册中，只能删除导入的快捷方式，无法删除源视频
- 源视频位于文件管理器中，可以移动到回收站
- 源视频位于下载文件夹的流心播放器文件夹中，可以彻底删除

### 为什么导入的视频一段时间后就失效了？

#### 可能有如下情况

1. 源视频位置移动、删除、改名等均会导致失效
2. 源视频处于外置设备中，设备拔插后失效，重新插回来**需要在弹出框中点击确定予以授权**，否则失效

### 为什么我的流心播放器这么大？

1. 这是因为隐私空间的视频都是复制进去的，一般不建议在隐私空间存放过多的视频
